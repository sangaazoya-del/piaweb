Батбилэг Б

Миний тухай

Намайг Батбилэг гэдэг. Би PI Academy-д программ хангамжийн инженерчлэлийн чиглэлээр сурч байгаа оюутан.

Одоогоор вэб хөгжүүлэлтийн үндсэн технологи болох HTML, CSS-ийг судалж, өөрийн гараар вэб хуудас бүтээх анхны алхмуудаа хийж байна.

Миний хувьд программчлал гэдэг нь зөвхөн код бичих бус, аливаа асуудлыг логик дарааллаар шийдвэрлэх, шинэ зүйл бүтээх боломж гэж ойлгодог.

Зорилго

HTML, CSS-ийн мэдлэгээ бататгаж, цаашид JavaScript болон бусад программчлалын технологийг эзэмшихийг зорьж байна.

Миний ойрын зорилго бол бие даан вэб сайт бүтээж, сурсан мэдлэгээ бодит төсөл болгон хэрэгжүүлж сурах юм.

Миний сурч буй зүйлс

  • HTML — вэб хуудасны бүтэц бүтээх
  • CSS — вэб хуудасны өнгө үзэмж, дизайныг тохируулах.
  • Программчлалын суурь — алгоритм, логик сэтгэлгээг хөгжүүлэх.
